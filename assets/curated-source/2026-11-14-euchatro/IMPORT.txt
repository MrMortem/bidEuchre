RUNTIME IMPORT
All 38 assets are imported into assets/pixel by tools/CuratedCardArtBuilder.
Run from the repository root: dotnet run --project tools/CuratedCardArtBuilder
The builder defaults to this source directory, reads labeled paths, and also supports the legacy manifest format.
assets/pixel/curated-art.json records each exported PNG, resolved ID, source/output dimensions, checksums,
source provenance, transform, and measured alpha. curated-art-preview.png shows all 38 textures.
Tickets retain their 2:3 aspect ratio at 256x384; gumballs and sigils are 128x128.
Enhancements use the existing 124x176 card-substrate dimensions.
Five boss arena PNGs retain their original 1536x1024 dimensions and exact source bytes.
Source originals and labeled files are unchanged. Existing assets are not deleted.

ARENA MAPPINGS
Arena resources are boss-arena-club, boss-arena-diamond, boss-arena-heart, boss-arena-spade,
and boss-arena-cursed. These are visual backgrounds, not FeatureCatalog gameplay items.
Their source runtimeId remains null intentionally; exported metadata identifies them as arena:<theme>.
Full arena backgrounds remain separate from the existing transparent table suit layers.
Desktop and web select Club, Diamond, Heart, Spade and Cursed for active boss Antes 1-5,
then repeat the visual sequence in endless play. Ordinary matches and menus keep their existing scenery.
The shop, collection and inventory use the ticket images without changing saved Tarot IDs or effects.
